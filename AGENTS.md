## Agent skills

### Issue tracker

Issues live in GitHub Issues for this repo; external pull requests are not a triage surface. See [docs/agents/issue-tracker.md](docs/agents/issue-tracker.md).

### Triage labels

Use the default five-label triage vocabulary: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See [docs/agents/triage-labels.md](docs/agents/triage-labels.md).

### Domain docs

Use a multi-context layout with a root `CONTEXT-MAP.md` pointing to per-area `CONTEXT.md` files. See [docs/agents/domain.md](docs/agents/domain.md).
